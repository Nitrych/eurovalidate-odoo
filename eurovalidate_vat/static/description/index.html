EuroValidate VAT Validation

Validate VAT numbers and fill in name & address — even when VIES is down

Odoo's built-in check only colours the VAT field green or red — and when VIES times out it silently falls back to a checksum. This module sends the number to the EuroValidate API (https://eurovalidate.com/odoo-vat-validation?utm_source=odoo&utm_medium=appstore&utm_campaign=description), which answers from a 24-hour cache with a confidence flag when the national register is unavailable, and pre-fills the registered company name and address on the partner.

What you get

  • Autofill: name, street, zip, city and country from the official register — only when the field is empty.
  • Works during outages: last known answer with confidence: medium, or an honest unavailable; never a false “valid”.
  • Audit evidence: request id, source and timestamp stored on every partner.
  • Coverage: 27 EU states, UK (paid plans), Norway, Switzerland, Australia; format checks for CL/TR/IL/MX/CA/PH.
  • Optional blocking of invalid numbers on save; outages and quota never block.
  • Weekly re-validation cron (off by default).

Setup in three steps

1. Get a free key

100 validations per month, no card: eurovalidate.com (https://eurovalidate.com/v1/auth/signup?utm_source=odoo&utm_medium=appstore&utm_campaign=step1).

2. Paste it in Settings

Settings → General Settings → EuroValidate. Keep Autofill on.

3. Save a partner with a VAT number

The number is validated, the name and address are filled in, the EuroValidate tab shows status and confidence.

Pricing of the API

The module is free (LGPL-3). The API has a free tier — 100 requests/month — and paid plans from €19/month (Starter, 500,000 requests/month). Most back offices validating a few hundred partners a month fit in Starter. Full pricing: eurovalidate.com/#pricing (https://eurovalidate.com/#pricing).

Requirements: Odoo 17.0 or 18.0 on Odoo.sh or on-premise (Odoo Online cannot install third-party Python modules). Python package requests.
